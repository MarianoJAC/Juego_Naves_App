# Galaxy Shooter

Un juego de disparos espacial para Android y iOS construido con React Native y Expo.

## Características

*   Modo de juego infinito.
*   Mueve la nave arrastrando el dedo por la pantalla.
*   La nave dispara automáticamente mientras se mueve.
*   Destruye enemigos para sumar puntos.
*   Evita chocar con los enemigos y sus balas.
*   Recoge potenciadores para mejorar tu arma hasta el nivel 3.
*   Gana una vida extra cada 10.000 puntos.
*   Pantalla de opciones para personalizar vidas, dificultad y velocidad del juego.

## Instalación

1.  Clona el repositorio.
2.  Instala las dependencias con `npm install`.

## Uso

Para ejecutar la aplicación, utiliza los siguientes comandos:

*   `npm run android` para ejecutar en un dispositivo o emulador de Android.
*   `npm run ios` para ejecutar en un dispositivo o emulador de iOS.
*   `npm run web` para ejecutar en un navegador web.

## Tecnologías Utilizadas

*   React Native
*   Expo
*   TypeScript
